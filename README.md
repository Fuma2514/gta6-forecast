Forecast Twitch concurrent-viewer quantiles hour by hour for the GTA VI release day,
starting from hour 1's known count. The model ranks the case's comparable launches by
the shape of their last 48 pre-release hours and by their absolute viewer level, takes
the four nearest, transfers their release-day ratio curves as the median path, and sizes
the quantile bands from those neighbors' residual spread on the log scale.

## Run it

```sh
python3 -P -s /bot/main.py
```
